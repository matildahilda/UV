# UAV Concept Visualization Lab

A professional visual engineering workspace for documenting a conceptual (non-operational)
unmanned aerial vehicle (UAV). Built for **concept visualization, educational engineering
documentation, and simulation-interface demonstration**.

This project is a *concept lab*: it is not a manufacturing design, not flight-tested data,
and not an approved engineering result. Every visual is an original illustration, and every
number in the dashboard is simulated — clearly marked as such.

## Tools used

- **Python 3.13** — generation and verification scripts
  (`src/generate_visuals.py`, `src/generate_diagrams.py`, `simulation/data_source.py`).
- **Node.js** — syntax check of the dashboard controller
  (`node --check simulation/dashboard/app.js`).
- **git** — project repository linked to your GitHub (see below).
- All visuals are vector (browser-independent); illustrations are generated
  programmatically by the Python scripts.

## Visual design style

The illustrations use a professional aerospace blueprint aesthetic:

- Dark navy blueprint background
- White and light-blue technical linework
- Subtle grid
- Clean monospaced typography, consistent labeling, minimal clutter

All visuals are **conceptual** — no real engineering results are implied.

## How to open the results

- **Illustrations (SVG)**: open `assets/uav_concept.svg`, `assets/uav_silhouette.svg`,
  `assets/structure_sections.svg`, `drawings/title_block.svg`,
  `drawings/technical_drawing_sheet.svg` and `diagrams/system_architecture.svg` in any
  browser or SVG viewer.
- **Dashboard**: open `simulation/dashboard/index.html` in a browser.

## Running the dashboard

```bash
# From the project root:
cd UAV_Concept_Lab
python -m http.server 8000
# Open http://localhost:8000/simulation/dashboard/index.html
```

The page fetches its feed-placeholder image from `../../assets/uav_silhouette.svg`;
serving from the project root makes this path resolve correctly.

The dashboard is a visual demonstration only — it shows artificially generated
("SIMULATED") telemetry and connects to no real aircraft or hardware.

## Regenerating the visuals

```bash
cd UAV_Concept_Lab
python src/generate_visuals.py        # assets/ + drawings/
python src/generate_diagrams.py       # diagrams/
python simulation/data_source.py      # simulation/telemetry_sim.json (simulated samples)
```

## Limitations (honest scope)

- **Not a manufacturing design.** These are concept visuals; no manufacturing geometry,
  tolerances, or approvals are implied or included.
- **No flight-tested or real-world data.** Everything is illustrative or simulated.
  Dashboard telemetry values are artificial and marked SIMULATED.
- **No real aircraft or control hardware.** The dashboard and data generator are local
  visual demonstrations; nothing connects to real devices.
- **No real-world test results have been claimed or invented.**
- **Not weaponized.** All content is for concept visualization, education and
  documentation of a conceptual UAV.
