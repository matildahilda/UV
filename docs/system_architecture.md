# System Architecture (Conceptual)

High-level, non-operational view of the relationships between the major system
blocks of the UAV concept.

## Diagrams

- `../diagrams/system_architecture.svg` — hand-generated vector diagram (primary).
- `../diagrams/system_architecture.mmd` — Mermaid source (for tools with Mermaid support).

Regenerate with:

```bash
python src/generate_diagrams.py
```

## Conceptual relationships

| From | To | Relationship |
| --- | --- | --- |
| Airframe | Power Management | Power integration |
| Power Management | Computing | Provides power |
| Computing | Sensors | Processes sensor data |
| Sensors | Communications | Data uplink (conceptual) |
| Communications | Operator Interface | Uplink (conceptual) |
| Operator Interface | Airframe | Control path (conceptual) |

## Notes

- Non-operational: no mission profiles, flight envelopes or performance numbers.
- No implementation-level hardware specs are implied.
- All labels and values shown are simulated/fictional.
- The diagram is generated by `src/generate_diagrams.py`; the SVG and `.mmd` outputs are kept in sync.
